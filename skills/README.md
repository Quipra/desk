# Desk skills

What an agent needs at the desk, one file per task. In the app the same text is served by the `guide` tool (`guide { topic }`), and `core` rides on the first `look`. Generated from `src/skills.ts` by `npm run skills`; edit there.

- geometry: constructions, proofs, anything that must be exact: bisectors, perpendiculars, incircles, tangents
- lettering: any label, letter, number or short word on the paper
- vectors: organic shapes, icons, characters, logos, anything the ruler and compass can't draw
- illustration: the request is a picture, a mood, a scene or a style rather than a diagram
- animation: anything should move, appear over time, wiggle, or be shown frame by frame
- recipes: you will draw something more than once, or want a brush or motion of your own
- collaboration: the person has drawn something, asks you to look, correct, continue or explain their marks
- layers: organizing a busy sheet, showing or hiding parts, ordering what draws on top, pasting copies
